===========================================================
  Photo Archive — 写真ギャラリー自動生成ツール
===========================================================

■ 使い方（3ステップ）

  1. generate_gallery.py と PhotoArchive.cmd を
     写真フォルダにコピー

  2. PhotoArchive.cmd をダブルクリック

  3. 完了！ _gallery/index.html がブラウザで開きます

  ※ Pillow は初回実行時に自動インストールされます
  ※ config ファイルの編集は不要です

■ 必要環境

  - Python 3.9 以上（インストール済みであること）

■ 仕組み

  - フォルダ内の画像を再帰的にスキャン
  - サムネイル（320px）と閲覧用（1600px）を自動生成
  - 年月ごとに整理されたHTMLギャラリーを出力
  - ダークテーマ、レスポンシブ対応、ライトボックス付き

■ 対応フォーマット

  .jpg .jpeg .png .gif .bmp .webp

■ 出力先

  写真フォルダ/_gallery/
    index.html        ... ギャラリーページ
    thumbnails/       ... サムネイル画像
    views/            ... 閲覧用画像

■ コマンドラインでも使えます

  python generate_gallery.py "C:\Users\写真\旅行"
